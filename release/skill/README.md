# bookcard skill

从书里提取学习卡片 ✓。

**做什么**：一本 PDF → 抽关键词和解释 → 打成一个 `.ttfc.zip` 卡包 ✓ →
导入 Flashcard App ✓，或者在本地浏览页里翻 ✓。

**不做什么**：引擎不调任何模型 ✓ —— 抽词和解释由**你自己的 agent**作答 ✓，
引擎只做确定性的活（取字、目录、切章节、定位、校验、打包）✓。

## 里面有什么

| 文件 | 是什么 |
|---|---|
| `SKILL.md` | skill 本体 ✓ —— agent 读它就知道流程和判据 ✓ |
| `INSTALL.md` | 怎么装（引擎 + skill + MCP）✓ |
| `harness/` | 四个 harness 的接入说明（DSH / Claude Code / Codex / Devin）✓ |
| `references/` | 步骤 1–2 的细账（怎么核对目录、怎么定层级）✓ |

## 快速开始

1. 照 `INSTALL.md` 装引擎和 skill ✓
2. 对 agent 说「把这本书做成学习卡片」✓
3. 产出的卡包在**下载文件夹**里 ✓ —— 拖进 Flashcard App 就能用 ✓

## 约定

- 只有**一道闸门**：目录确认 ✓ —— 抽词没有第二道闸门 ✓
- 公开版卡包**不许带书页图** ✓，必须带书指纹 ✓
- 引擎**不写 key、不读 key** ✓
